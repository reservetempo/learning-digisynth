Building a digital synthesizer, explained

Somewhere on this machine, a 13-phase plan is turning into a real instrument: six complete polyphonic synths running side by side on six CPU cores, driven by twelve hardware knobs and drawn on a tablet screen. The plan that describes it is written for a machine to execute, and it reads like it. This site is the other half — one page per idea, in English, with the code, the vocabulary, and the reason anyone would do it that way.

Read it in order, or drop into whatever sounds interesting. Every page is self-contained, defines the words it uses, and links to the glossary for the ones it borrows. New here? Start with a1, then how to read this site.
